<E.h2><GuideIcon name="ti-info-circle" />{"1. MITRE ATLASとは何か"}</E.h2>
{"\n                    "}
<E.p>
{"\n                        "}
<E.strong>
{"MITRE ATLAS"}
</E.strong>
{"(Adversarial Threat Landscape for\n                        Artificial-Intelligence\n                        Systems)は、AIおよび機械学習(ML)システムを狙う攻撃者の戦術・技術を体系化した、無償で公開されている「生きた」ナレッジベースです。非営利団体MITREが、産業界・政府・学術機関のコミュニティと協力しながら継続的に更新しています。2021年6月にMicrosoftとの協業から生まれ、現在は\n                        atlas.mitre.org で公開されています。\n                    "}
</E.p>
{"\n                    "}
<E.p>
{"\n                        ポイントは「理論上の脅威リスト」ではなく、"}
<E.strong>
{"実際に観測された攻撃や、AIレッドチームによる実証済みのデモンストレーションに基づいて構築されている"}
</E.strong>
{"という点です。ATLASは認証取得のための規格でも、コントロール(統制)カタログでもありません。あくまで「AIシステムがどのように攻撃されるか」を体系立てて理解するための知識ベースであり、脅威モデリング・レッドチーム演習・検知エンジニアリングに使うことを目的としています。\n                    "}
</E.p>
{"\n                    "}
<E.div className={"callout"}>
{"\n                        "}
<GuideIcon name="ti-bulb" />
{"\n                        "}
<E.p>
{"\n                            初学者がまず押さえるべきことは1つだけです。"}
<E.strong>
{"ATLAS = ATT&CKと同じ「Tactics → Techniques → Mitigations/Case\n                                Studies」という構造を、AI/ML特有の攻撃面(モデル、学習データ、推論API、RAG、AIエージェントなど)に適用したもの。"}
</E.strong>
{"\n                        "}
</E.p>
{"\n                    "}
</E.div>
