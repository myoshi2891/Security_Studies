<E.h3>{"5-1. 学習データ・モデルへの攻撃"}</E.h3>
{"\n                    "}
<E.h4><E.span className={"tag"}>
{"AML.T0020"}
</E.span>{"Training Data Poisoning"}</E.h4>
{"\n                    "}
<E.p>
{"\n                        攻撃者が学習データやそのラベルを改ざんし、モデルに気づかれにくい欠陥や裏口(バックドア)を埋め込む攻撃です。ラベルを変えなくても成立する場合があり、仕込んだ欠陥は特定の入力パターン("}
<E.code>
{"AML.T0043.004 Insert Backdoor Trigger"}
</E.code>
{")によって後から起動されます。汚染されたデータは、サプライチェーン経由や、初期アクセス後の直接改ざんによって混入します。\n                    "}
</E.p>
{"\n\n                    "}
<E.h4><E.span className={"tag"}>
{"AML.T0018.000"}
</E.span>{"Poison AI Model"}</E.h4>
{"\n                    "}
<E.p>
{"\n                        学習データそのものではなく、"}
<E.strong>
