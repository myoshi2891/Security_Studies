## Findings considered and rejected

- **IAM / ガバナンスの独立ページを最初から作る**: 却下。資格ページ内のセクションで開始し、
  重複が生じてから切り出す方が手戻りが少ない (001 の設計原則参照)。
- **CASE / GWEB の対策深掘りページ**: 却下。対象 5 資格 (ISSAP / SABSA / CSSLP /
  GCP PCSE / AWS SCS) に含まれない。既存の比較ガイド (`/docs/certifications`) で十分。
- **模擬問題・演習のインタラクティブ機能**: 保留。コンテンツが揃う前の機能開発は空回りする。
  001 の「追加検討カテゴリ」に将来候補として記録済み。
- **更新チェックの自動化 (RSS / スクレイピング)**: 保留。まず 006 の手動運用を確立し、
  形骸化しない頻度を見極めてから自動化する。
